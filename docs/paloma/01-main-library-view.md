# 01. Головний екран бібліотеки (Main Library View)

Головний екран бібліотеки **Paloma** є центральним модулем перегляду, швидкої фільтрації та каталогізації фотоархіву. Інтерфейс відтворює ергономіку Picasa, але реалізований на **React 18** та **Bootstrap 5** з урахуванням потреб користувачів похилого віку.

---

```

+----------------------+------------------------------------------------------------------+
| <LeftSidebar />      | <VirtualPhotoGrid /> (Реалізовано через react-window)            |
| (Bootstrap ListGroup)|                                                                  |
```

## 💻 Специфікація React-компонентів

### 1. `<TopNavbar />` — Пошук та глобальні фільтри
* **Компоненти Bootstrap:** `navbar`, `form-control-lg`, `btn-group`.
* **Функціонал:**
  * **Пошуковий рядок:** Текстове поле збільшеного розміру з debounce (300ms). Шукає по назвах файлів, тегах, підписах та розпізнаних обличчях через SQLite FTS (Full-Text Search).
  * **Фільтр ⭐ Starred:** Перемикач відображення тільки фото з зірочкою (`is_starred = 1`).
  * **Фільтр носіїв:** Швидка фільтрація (Фото / Відео / ГІФ).

### 2. `<LeftSidebar />` — Ієрархія та навігація
* **Компоненти Bootstrap:** `list-group`, `accordion`, `badge`.
* **Розділи:**
  1. **Колекції (Collections):** Обране, Останні завантаження, Фото без тегів.
  2. **Люди (People):** Мініатюри знайдених облич з лічильниками фото.
  3. **Дерево папок (Folder Tree):** Відображення локальної структури папок комп'ютера з автоматичним оновленням через Node.js.

### 3. `<VirtualPhotoGrid />` — Плинна сітка мініатюр
* **Бібліотека:** `react-window` + `react-virtualized-auto-sizer`.
* **Призначення:** Безперешкодне відображення 100,000+ фотографій без зависання браузера.
* **Картка фотографії `<PhotoCard />`:**
  * Завантажує оптимізовані мініатюри (WebP / JPEG 300px), згенеровані Node.js `sharp`.
  * Відображає бейджи: ⭐ (Обране), 📍 (Геолокація), 💬 (Наявність підпису).
  * Подвійний клік — перехід у модуль редагування [`02-editor-view.md`](file:///Users/orozhyk/proj/picassa/docs/paloma/02-editor-view.md).

### 4. `<PhotoTray />` — Буфер вибору (Фотопіддон)
* **Стан React (Zustand/Redux):** Глобальний масив `selectedPhotos: Photo[]`.
* **Функціонал:**
  * Дозволяє накопичувати фотографії з різних папок для спільних дій.
  * Кнопка **"📌 Зафіксувати (Hold)"** — залишає обрані фотографії при переході між папками.
  * Швидкі кнопки дій: **"📤 Експорт"**, **"🖨️ Друк"**, **"🖼️ Колаж"**, **"🎬 Слайд-шоу"**.

## ♿ Особливості Senior-Friendly UX / UI

1. **Великі інтерактивні зони:** Розмір кнопок мінімум `48px x 48px` для зручного попадання мишею.
2. **Високий контраст:** Відповідність стандарту WCAG AAA (темний текст `#111111` на світлому тлі `#FFFFFF` або чітка контрастна темна тема).
3. **Текстові пояснення:** Відсутність одиночних іконок без текстових підписів.
4. **Гарячі клавіші з візуальною підказкою:** Підтримка клавіш `Space` (повноекранний перегляд), `Delete` (видалення в кошик), `Enter` (відкрити редактор).
