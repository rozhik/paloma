# Paloma — Сучасний фотоменеджер (Спадкоємець Google Picasa)

> **Google Picasa більше не підтримується та вважається «мертвим» проєктом.**  
> **Paloma** є прямим технологічним та концептуальним спадкоємцем («дочкою») Picasa. Проєкт розроблено на сучасному веб/десктоп стеку для відродження класичних фотоархівів та забезпечення комфортного, звичного інтерфейсу для людей похилого віку.

---

## 🎯 Мета та філософія проєкту

* **Відродження фотоархівів:** Підтримка локальних колекцій будь-якого розміру з миттєвим індексуванням та неруйнівним редагуванням.
* **Senior-Friendly UI (Орієнтація на людей похилого віку):** Великі шрифти, високий контраст, чіткі великі кнопки, текстові підказки, спрощена навігація без заплутаних меню.
* **Сучасний технологічний стек:** Поєднання продуктивності Node.js, надійності SQLite та гнучкості React з Bootstrap CSS.
* **Приватність за замовчуванням:** Усі дані, метадані та розпізнані обличчя обробляються виключно локально на ПК користувача без примусової відправки в хмару.

## 🛠 Стек розробки (Tech Stack)

| Шар | Технологія | Опис та призначення |
| :--- | :--- | :--- |
| **Frontend UI** | [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) | Інтерактивний, декларативний та типізований інтерфейс |
| **Стилізація** | [Bootstrap CSS 5](https://getbootstrap.com/) + Icons | Дизайн-система з високою доступністю (a11y) та великими контролами |
| **Backend / Runtime** | [Node.js](https://nodejs.org/) (Express / Electron API) | Робота з файловою системою, фоновий сканер папок, REST/IPC API |
| **База даних** | [SQLite](https://www.sqlite.org/) (`better-sqlite3` / `drizzle-orm`) | Локальна реляційна БД для збереження каталогу, облич, геолокацій та історії правок |
| **Обробка зображень** | [Sharp](https://sharp.pixelplumbing.com/) + Canvas API | Швидкий графічний рушій для генерації мініатюр та експорту фото у високій якості |
| **Метадані** | `exiftool-vendored` / `exif-reader` | Читання та запис EXIF, IPTC, XMP метаданих |
