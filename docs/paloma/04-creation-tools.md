# 04. Інструменти створення (Creation Tools: Collages & Movies)

Модуль інструментів створення **Paloma** надає можливість формувати з обраних фотографій художні фотоколажі, генеративні альбоми та відео-слайд-шоу з музичним супроводом.

---

## 🖼️ 1. Конструктор фотоколажів (Picture Collage Builder)

Конструктор колажів базується на інтерактивному канвасі **React + `fabric.js`** (або `konva`), що дозволяє вільно переміщувати, обертати та масштабувати зображення.

```
+-----------------------------------------------------------------------------------------+
| 🖼️ КОНСТРУКТОР ФОТОКОЛАЖІВ                                                               |
+-----------------------------------+-----------------------------------------------------+
| ПАНЕЛЬ НАЛАШТУВАНЬ (LEFT TABS)    | ІНТЕРАКТИВНИЙ КАНВАС КОЛАЖУ                         |
|                                   |                                                     |
| РЕЖИМИ КОЛАЖУ:                    |  +-----------------------------------------------+  |
| (🔘) Хаотична купа (Picture Pile) |  |   +---------+                                 |  |
| ( ) Автоматична сітка (Grid)     |  |   | Фото 1  |   +-----------+                 |  |
| ( ) Мозаїка (Mosaic)              |  |   +---------+   | Фото 2    |                 |  |
| ( ) Мультиекспозиція             |  |                 +-----------+                 |  |
|                                   |  |     +------------------+                     |  |
| НАЛАШТУВАННЯ:                     |  |     | Фото 3           |                     |  |
| • Межа світлини: [ 5px біла ]     |  |     +------------------+                     |  |
| • Тінь під фото: [ Увімкнено ]    |  +-----------------------------------------------+  |
| • Тло: [ 🎨 Колір / Зображення ]  |                                                     |
+-----------------------------------+-----------------------------------------------------+
| [ 🔀 Перемішати фото ]  [ 💾 Зберегти колаж ]  [ 📤 Експортувати в JPG (High-Res) ]       |
+-----------------------------------------------------------------------------------------+
```

### Режими генерації колажу:
1. **Хаотична купа (Picture Pile):** Фотографії розкидаються по канвасу з випадковими кутами нахилу (-15° до +15°) та тонкими білими рамками (ефект Polaroid).
2. **Мозаїка (Mosaic):** Автоматичне заповнення прямокутної області фотографіями різного розміру без прогалин.
3. **Регульована сітка (Grid):** Класичне вирівнювання з фіксованою кількістю колонок та закругленими кутами.

### Експорт колажу у високій якості:
* На клієнті `fabric.js` експортує векторну JSON-сцену колажу.
* Node.js backend отримує JSON, підвантажує оригінали фото у високій роздільності та рендерить підсумковий файл JPG/PNG (наприклад, 4000x3000px) для друку.

## 🎬 2. Редактор відео та слайд-шоу (Movie Maker / Slideshow Creator)

Модуль перетворює статичні фотографії на динамічні MP4-відеоролики з ефектом Ken Burns (плавний зум та панорамування) і фоновою музикою.

```
+-----------------------------------------------------------------------------------------+
| 🎬 СТВОРЕННЯ ВІДЕО СЛАЙД-ШОУ                                                            |
+-----------------------------------------------------------------------------------------+
| НАЛАШТУВАННЯ ВІДЕО:              | ТАЙМЛАЙН ТА ПРЕВ'Ю СЛАЙДІВ                          |
| • Роздільна здатність:           | +--------------------------------------------------+ |
|   [ 1080p Full HD (1920x1080) ]  | | [ ▶ Плей ]  00:01 / 00:30                        | |
| • Тривалість слайда: [ 3 сек ]   | +--------------------------------------------------+ |
| • Ефект перехода: [ Розчинення ] | ТАЙМЛАЙН ФОТОГРАФІЙ:                                 |
| • Фонова музика:                 | [ Фото 1 ] ➔ [ Фото 2 ] ➔ [ Фото 3 ] ➔ [ Фото 4 ]   |
|   [ 🎵 audio_track.mp3 ] [📁]    | 🎵 Аудіо-доріжка: [===============================] |
+----------------------------------+------------------------------------------------------+
| [ 🚀 Згенерувати MP4 відео ]                                         [ ❌ Скасувати ]   |
+-----------------------------------------------------------------------------------------+
```

### Технологія генерації відео (Node.js & FFmpeg):
* **Прев'ю в реальному часі:** Реалізовано через React Canvas + Web Audio API.
* **Рендеринг підсумкового MP4:**
  1. Frontend передає на сервер список фотографій, порядок, тривалість та аудіофайл.
  2. Backend Node.js використовує бібліотеку `fluent-ffmpeg` (або `ffmpeg-static`):
     ```bash
     ffmpeg -loop 1 -t 3 -i img1.jpg -loop 1 -t 3 -i img2.jpg \
            -i music.mp3 -filter_complex "fade,zoompan" -c:v libx264 -pix_fmt yuv420p output.mp4
     ```
  3. Готовий файл MP4 зберігається у папці `Paloma Movies` та додається до бібліотеки.

## 🌐 3. Веб-альбом та експорт презентацій (HTML Web Album)

* **Генерація автономного веб-сайту:** Створення папки з самодостатнім HTML/CSS/JS альбомом, який можна відкрити в будь-якому браузері без інтернету чи записати на USB-флешку для родичів.
* **Senior-Friendly переглядач:** Великі кнопки «Вперед/Назад», автоматичне слайд-шоу, адаптивність під планшети та телевізори.
