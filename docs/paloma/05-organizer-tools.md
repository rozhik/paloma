# 05. Організація, розпізнавання облич та геодані (Organizer Tools)

Розділ описує інтелектуальні інструменти впорядкування фотоархіву в **Paloma**: автоматичне розпізнавання та кластеризація облич, геолокація на карті світу та інструменти масової обробки.

---

## 👤 1. Модуль розпізнавання облич (People / Face Recognition)

Система розпізнає обличчя людей на фотографіях і групує їх за персонами. **Усі обчислення відбуваються 100% локально на пристрої без відправки в хмару.**

```
+-----------------------------------------------------------------------------------------+
| 👤 ЛЮДИ ТА ОБЛИЧЧЯ (PEOPLE)                                                              |
+-----------------------------------------------------------------------------------------+
| ПІДТВЕРДЖЕНІ ПЕРСОНИ:                                                                   |
|  +--------------+   +--------------+   +--------------+   +--------------+              |
|  |  ( Обличчя ) |   |  ( Обличчя ) |   |  ( Обличчя ) |   |  ( Обличчя ) |              |
|  |  Бабуся Олена|   |  Дідусь Іван |   |  Оксана      |   |  Маленький Тарас             |
|  |   42 фото    |   |   38 фото    |   |   19 фото    |   |   55 фото    |              |
|  +--------------+   +--------------+   +--------------+   +--------------+              |
|                                                                                         |
| ❓ НЕРОЗПІЗНАНІ ОБЛИЧЧЯ (Потребують вашого підтвердження):                              |
|  +-----------------------------------------------------------------------------------+  |
|  | ( Фото обличчя )  Це **Бабуся Олена**?   [ ✅ Так, це вона ]  [ ❌ Ні / Інша людина ]|  |
|  +-----------------------------------------------------------------------------------+  |
+-----------------------------------------------------------------------------------------+
```

### Технологічна реалізація:
* **Графічний нейромережевий рушій:** `@vladmandic/face-api` (або ONNX Runtime Web через WebGL/WebGPU).
* **Етапи розпізнавання:**
  1. **Детекція (Face Detection):** Пошук координат прямокутника обличчя (`SSD MobileNet V1`).
  2. **Векторизація (Face Landmarks & Embeddings):** Генерація 128-мірного вектора унікальних рис обличчя.
  3. **Кластеризація у SQLite:** Розрахунок косинусної відстані між векторами для угруповання схожих облич під єдиним ім'ям.

---

## 📍 2. Інтерактивна карта та геодані (Places & Map View)

Модуль надає наочну карту світу з маркерами та кластерами фотографій, прив'язаних до координат.

```
+-----------------------------------------------------------------------------------------+
| 📍 КАРТА СВІТЛИНИ (PLACES MAP)                                                           |
+-----------------------------------+-----------------------------------------------------+
| СИСК ФОТО БЕЗ ГЕОМІТОК:           | ІНТЕРАКТИВНА КАРТА LEAFLET (OpenStreetMap)          |
|                                   |                                                     |
| Перетягніть фото на карту для     |  +-----------------------------------------------+  |
| прив'язки координати:             |  | [ + ]                         [ 🔵 Київ (42) ] |  |
|                                   |  | [ - ]                                         |  |
|  +----------+  +----------+       |  |          [ 🔴 Львів (15) ]                    |  |
|  | IMG_0101 |  | IMG_0102 |       |  |                                               |  |
|  +----------+  +----------+       |  |                      [ 🟡 Одеса (28) ]        |  |
|                                   |  +-----------------------------------------------+  |
+-----------------------------------+-----------------------------------------------------+
| [ 💾 Зберегти GPS у EXIF метадані ]                                                     |
+-----------------------------------------------------------------------------------------+
```

### Технічні деталі (React + Leaflet):
* **Компоненти:** `react-leaflet`, `leaflet.markercluster`.
* **Авто-зчитування EXIF:** Базові координати `GPSLatitude` / `GPSLongitude` автоматично зчитуються під час індексації папки через `exiftool-vendored`.
* **Мануальна прив'язка (Drag & Drop):** Перетягування знімків з фотопіддону прямо на точку картографічного полотна встановлює нову позицію з оновленням SQLite та метаданих.

## 🏷️ 3. Пакетні операції та перейменування (Batch Tools)

Інструменти масового впорядкування фотографій:

1. **Пакетне перейменування (`<BatchRenameModal />`):**
   * Шаблони перейменування: `[Дата]_[Назва_Папки]_[Номер]`.
   * Приклад: `2024-05-15_Карпати_001.jpg`.
   * Реалізується безпосередньо в Node.js через `fs.promises.rename` із синхронним оновленням шляхів у SQLite.
2. **Зсув часових міток (Adjust Date & Time):**
   * Масове коригування часу при некоректній даті на фотоапараті (наприклад, зсув на +2 години).
3. **Пакетний тегінг (Batch Tagging):**
   * Одночасне призначення ключевих слів (наприклад, `"Відпустка"`, `"Гори"`, `"Сім'я"`) для всіх фотографій з піддону.
