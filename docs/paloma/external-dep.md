# Зовнішні залежності проєкту Paloma (External Dependencies)

У цьому документі згруповано всі необхідні npm-пакети та системні залежності, необхідні для реалізації фотоменеджера **Paloma** на стеку **React, TypeScript, Node.js, SQLite, Bootstrap CSS**.

---

## 📦 1. Backend & Server Dependencies (Node.js & SQLite)

| Пакет | Версія | Призначення та роль у Paloma |
| :--- | :--- | :--- |
| **`express`** | `^4.19.0` | Легковаговий HTTP/REST сервер для зв'язку між React UI та локальним Node.js |
| **`better-sqlite3`** | `^9.4.0` | Швидка підключувана база даних SQLite з синхронним API для локальних файлів |
| **`drizzle-orm`** | `^0.30.0` | Легка, типізована ORM для зручної роботи з базою SQLite у TypeScript |
| **`drizzle-kit`** | `^0.20.0` | Інструмент генерації та міграцій схем SQLite |
| **`sharp`** | `^0.33.0` | Високопродуктивний C++ графічний рушій (libvips) для генерації WebP/JPEG мініатюр та рендерингу підсумкових фото |
| **`chokidar`** | `^3.6.0` | Надійний крос-платформений відстежувач змін у файловій системі (сканер папок) |
| **`exiftool-vendored`** | `^26.0.0` | Швидке та повне читання/запис EXIF, IPTC, XMP метаданих фотографій |
| **`fluent-ffmpeg`** | `^2.1.2` | Оболонка для FFmpeg для збірки MP4 відео та слайд-шоу з фоновою музикою |
| **`ffmpeg-static`** | `^5.2.0` | Бінарні збірки FFmpeg без необхідності ручного встановлення користувачем |
| **`xxhashjs`** | `^0.2.2` | Супершвидке обчислення хешів файлів для дедуплікації зображень |
| **`cors`** | `^2.8.5` | Дозвіл крос-доменних запитів від Vite розробницького сервера |
