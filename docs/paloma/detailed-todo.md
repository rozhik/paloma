# Детальний покроковий план розробки Paloma (Detailed TODO & Roadmap)

Повний чек-лист створення системи **Paloma** з нуля до стабільного релізу. План розбито на 8 послідовних етапів.

---

## 🏗️ Етап 1: Ініціалізація проєкту та базова інфраструктура (Phase 1)

- [x] **1.1. Налаштування репозиторію та середовища:**
  - [x] Ініціалізувати монорепозиторій або двокомпонентний проєкт (Client: React+Vite, Server: Node.js+Express).
  - [x] Налаштувати `tsconfig.json` з суворим режимом перевірки типів TypeScript.
  - [x] Підключити ESLint та Prettier для єдиного стилю коду.
- [x] **1.2. Налаштування бази даних SQLite:**
  - [x] Встановити `better-sqlite3` та `drizzle-orm`.
  - [x] Створити файли схем таблиць (`folders`, `photos`, `edits`, `people`, `tags`, `albums`).
  - [x] Написати скрипт початкових міграцій `drizzle-kit generate:sqlite`.
- [x] **1.3. Створення базового Node.js Express сервера:**
  - [x] Налаштувати REST API роути для роботи з папками та фотографіями.
  - [x] Налаштувати роздачу статичних файлів-мініатюр через `express.static`.

## 📁 Етап 2: Сканер файлів, метадані та сервіс генерації мініатюр (Phase 2)

- [x] **2.1. Реалізація відстеження папок (Chokidar Scanner):**
  - [x] Написати фонову службу `FolderScannerService` на базі `chokidar`.
  - [x] Реалізувати обробники подій створення (`add`), видалення (`unlink`) та зміни (`change`) файлів зображень.
- [x] **2.2. Сервіс метаданих та хешування:**
  - [x] Підключити `exiftool-vendored` для витягування EXIF дати, орієнтації, ISO та GPS координат.
  - [x] Реалізувати швидкий розрахунок хешу файлів через `xxhashjs` для виявлення дублікатів.
- [x] **2.3. Генератор мініатюр (Sharp Engine):**
  - [x] Створити воркер генерації WebP мініатюр 150px (для сітки) та 600px (для швидкого прев'ю).
  - [x] Зберігати мініатюри у службовому кєші `.paloma/cache/`.

  - [x] Побудувати інструмент кадрування `<CropTool />` з вибором пропорцій.
- [x] **4.2. Інструменти корекції та ефектів:**
  - [x] Реалізувати слайдери вирівнювання горизонту, світосили (Fill Light), контрасту, температури.
  - [x] Додати пресети ефектів (Сепія, Ч/Б, Чіткість, Віньєтка).
- [x] **4.3. Збереження та серверний рендеринг:**
  - [x] Налаштувати запис опису правок у форматі JSON DAG у базу SQLite та сайдкар-файл `.paloma.json`.
  - [x] Реалізувати підсистему Node.js `sharp` для запікання фінальних зображень при експорті.
- [ ] **4.4. Перехід на формат `.paloma.json` v2 ([08-paloma-json-format.md](../picassa/08-paloma-json-format.md)):**
  - [ ] Описати типи v2 у `shared/types.ts`: `folder`, `albums`, `people`, `photos` з `edits` як впорядкованим масивом фільтрів, `import`, `extra`.
  - [ ] Мігрувати v1 → v2: `is_starred` → `star`, `edits.crop` `[x, y, w, h]` → `crop64` з `left/top/right/bottom`, `straighten` → `tilt`, `tuning` → `finetune2`/`fill`/`unsharp2` у масиві `edits`.
  - [ ] Переписати `SidecarService` під v2 (атомарний запис, стабільний порядок ключів) і читати v1-файли з автоматичною міграцією.
  - [ ] Тести міграції на прикладах v1-файлів.
