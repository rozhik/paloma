# 03. Модулі імпорту, експорту та друку (Import, Export & Print)

Цей розділ описує модальні вікна та майстри діалогу у **Paloma** для захоплення/імпорту зображень з носіїв, пакетного експорту оброблених фотографій та підготовки до друку.

---

## 📥 1. Модуль імпорту та сканування папок (Folder Scanner & Import)

Архітектура імпорту в Paloma працює у двох режимах: **автоматичне фонове сканування** та **ручний майстер імпорту**.

```
+-----------------------------------------------------------------------------------------+
| 📥 МЕНЕДЖЕР ПАПОК ТА ІМПОРТУ                                                             |
+-----------------------------------------------------------------------------------------+
| Оберіть папки на комп'ютері для автоматичного відстеження:                              |
|                                                                                         |
|  [☑] 📁 C:/Users/Name/Pictures (Зображення)          -- (🔘 Сканувати завжди)           |
|  [☑] 📁 D:/PhotoArchive (Архів Фотографій)           -- (🔘 Сканувати завжди)           |
|  [ ] 📁 E:/ExternalDrive (Зовнішній диск)            -- (⚪ Сканувати один раз)        |
|                                                                                         |
| Прогрес сканування: [=======================>........] 68% (Індексовано 2,450 фото)     |
+-----------------------------------------------------------------------------------------+
| [ ➕ Додати папку ]                             [ ❌ Скасувати ]  [ 💾 Зберегти налаштування ] |
+-----------------------------------------------------------------------------------------+
```

### Технічні деталі імпорту (Node.js & SQLite):
* **Сканер диска:** Використовує бібліотеку `chokidar` у Node.js для відстеження подій додавання/видалення/зміни файлів (`add`, `unlink`, `change`).
* **Дедуплікація (Hash check):** Обчислення швидкодіючого хекса-хешу (`xxhash` / `md5`) для виявлення однакових знімків під час імпорту з флешок чи фотоапаратів.
* **Генерація мініатюр:** Фоновий воркер Node.js через `sharp` створює 2 типи мініатюр: `small` (150px WebP) та `medium` (600px WebP) для плинної сітки.

## 📤 2. Майстер пакетного експорту (Export Wizard)

Майстер експорту обробляє знімки, накопичені у **Фотопіддоні (Photo Tray)** або вибраній папці.

```
+-----------------------------------------------------------------------------------------+
| 📤 ЕКСПОРТ ОБРАНИХ СВІТЛИН (3 фотографії)                                               |
+-----------------------------------------------------------------------------------------+
| 1. Папка призначення:                                                                   |
|    [ D:/ExportedPhotos/2024_Карпати_Оброблені             ] [ 📁 Огляд... ]            |
|                                                                                         |
| 2. Розмір зображень:                                                                    |
|    (🔘) Оригінальний розмір                                                             |
|    ( ) Зменшити до: [ 1920 ] пікселів по довшій стороні                                 |
|                                                                                         |
| 3. Якість стиснення (JPEG): [==========O..........] 85%                                  |
|                                                                                         |
| 4. Водяний знак (Watermark):                                                            |
|    [☑] Додати підпис: [ (c) Фотоархів Сім'ї Петренків     ]                             |
+-----------------------------------------------------------------------------------------+
| [ 🚀 Розпочати експорт ]                                             [ ❌ Скасувати ]   |
+-----------------------------------------------------------------------------------------+
```

### Технологія виконання експорту:
* При виклику експорту React надсилає запит на backend Node.js з параметрами експорту та масивом ID фото.
* Node.js бере оригінал із диска, застосовує ланцюжок неруйнівних правок із JSON DAG (`sharp`), змінює розмір, додає текстовий водяний знак через Canvas/SVG оверлей і зберігає підсумкові файли.

## 🖨️ 3. Модуль підготовки та макетування друку (Print Layout)

Модуль друку в Paloma розроблений для максимально простого виводу фотографій на домашній принтер.

```
+-----------------------------------------------------------------------------------------+
| 🖨️ ДРУК ФОТОГРАФІЙ                                                                      |
+-----------------------------------------------------------------------------------------+
| МАКЕТ СТОРІНКИ:                  | ПРЕВ'Ю СТОРІНКИ ДРУКУ                                |
| (🔘) Повна сторінка (A4)         | +--------------------------------------------------+ |
| ( ) 10 x 15 см (2 фото на аркуш) | | +--------------------+  +--------------------+ | |
| ( ) 9 x 13 см (4 фото на аркуш)  | | |                    |  |                    | | |
| ( ) Паспортний формат (8 фото)   | | |      Фото 1        |  |      Фото 2        | | |
|                                  | | |                    |  |                    | | |
| КІЛЬКІСТЬ КОПІЙ: [ 1 ]           | | +--------------------+  +--------------------+ | |
| [☑] Кадрувати за розміром осередку| +--------------------------------------------------+ |
+----------------------------------+------------------------------------------------------+
| [ 🖨️ Надрукувати зараз ]                                             [ ❌ Скасувати ]   |
+-----------------------------------------------------------------------------------------+
```

### Реалізація макетування друку:
* Використовує **CSS `@media print`** та сітку `CSS Grid`.
* Автоматичне розміщення обраних знімків із Фотопіддону на віртуальних сторінках A4 з точними фізичними розмірами у міліметрах (`mm`).
* Виклик стандартного діалогу друку браузера/Electron `window.print()`.
