# 01. Головний екран бібліотеки (Main Library View)

Головний екран бібліотеки Picasa — це центральний хаб додатка, призначений для перегляду, фільтрації, сортування та каталогізації всього медіа-контенту на комп'ютері.

---

## 1. Верхня панель пошуку та фільтрації (Top Bar)

1. **Пошуковий рядок (Search Box):**
   * Миттєвий пошук у реальному часі за назвою файлу, тегами, підписами, геолокацією або розпізнаними іменами людей.
2. **Швидкі фільтри (Quick Filter Buttons):**
   * ⭐ **Starred Photos:** Показ тільки фотографій, позначених зірочкою (обране).
   * 👤 **Faces:** Відбір фотографій, на яких виявлено обличчя людей.
   * 🎥 **Movies:** Фільтрація тільки відеофайлів.
   * 📍 **Geotagged:** Показ лише тих знімків, які мають геолокаційні позначки.
3. **Шкала часу (Date Range Slider):**
   * Дозволяє звузити діапазон відображення фото за датою зйомки (від конкретного року/місяця до всього архіву).

---

## 2. Ліва бічна панель (Left Navigation Sidebar)

Дерево навігації розділено на 4 основні секції:

* **Albums (Віртуальні альбоми):**
  * Динамічні колекції (не змінюють розташування файлів на диску).
  * Автоматичні альбоми: *Starred Photos*, *Last Import*.
* **People (Люди):**
  * Список розпізнаних облич із аватарками та кількістю знімків для кожної особи.
* **Folders (Папки):**
  * Фізичні директорії комп'ютера, розпізнані Picasa.
  * Підтримує два режими відображення:
    * **Flat Folder View:** Простий хронологічний список папок.
    * **Tree View:** Деревовидна структура файлової системи (аналог Провідника).
* **Projects (Проекти):**
  * Збережені фотоколажі, змонтовані відеоролики, експортовані слайд-шоу.

Поруч із назвою кожної папки знаходиться зелений/червоний індикатор синхранізації з мережею Google Web Albums.

---

## 3. Центральна область — Light Box (Сітка мініатюр)

* **Безперервна вертикальна прокрутка:** Усі папки та альбоми розташовані в єдиній нескінченній стрічці Light Box.
* **Заголовки папок (Folder Headers):**
  * Назва папки, дата створення, кількість фотографій.
  * Кнопка швидкого запуску слайд-шоу папки `[▶]`.
  * Перемикач синхранізації з веб-альбомами `[Sync to Web]`.
* **Мініатюри фотографій:**
  * Відображення іконки зірочки (якщо додано в обране).
  * Позначки наявності відредагованого стану або геотегу.
  * Контекстне меню при правому кліку: швидкий поворот, видалення, позначення зірочкою, виклик властивостей EXIF.

---

## 4. Нижній фотопіддон (Photo Tray) та Панель дій

Фотопіддон (Photo Tray) — унікальна особливість Picasa, що діє як тимчасовий буфер обміну для фото з різних папок.

* **Елементи Photo Tray:**
  * Мініатюри вибраних знімків.
  * Кнопка **Hold (Закріпити):** Фіксує поточний вибір під час навігації іншими папками.
  * Кнопка **Clear (Очистити):** Скидає поточний вибір.
* **Кнопки швидкої дії (Action Toolbar):**
  * 🌐 **Upload / Sync:** Завантаження в Google Web Albums / Google Photos.
  * 📦 **Export:** Відкриття діалогу експорту зі зміною розміру та якості.
  * 🖨️ **Print:** Відкриття майстра друку.
  * 🎨 **Collage:** Перехід у режим створення фотоколажу.
  * 🎬 **Movie:** Перехід у режим монтажу відеоролика.
  * ✉️ **Email:** Швидке відправлення вибраних фото електронною поштою.
* **Ползунок зуму мініатюр (Thumbnail Zoom Slider):** Регулювання розміру іконок у сітці Light Box (від дрібних до великих).
