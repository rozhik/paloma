# 03. Екрани імпорту, експорту та друку (Import & Export Dialogs)

Цей розділ описує діалогові вікна та майстри, які використовуються для введення медіафайлів у Picasa та їх подальшого збереження, друку або публікації.

---

## 1. Екран імпорту медіафайлів (Import Screen)

Екран імпорту активується натисканням кнопки **Import** у верхньому лівому кутку Picasa.

```
+-----------------------------------------------------------------------------------------+
| [ Import From: 📷 Canon EOS (Drive G:) ▼ ]                      [ Destination: Pictures] |
+-----------------------------------------------------------------------------------------+
| ДЖЕРЕЛО ТА МІНІАТЮРИ ДЛЯ ІМПОРТУ                                                        |
|                                                                                         |
| [☑] IMG_001.JPG   [☑] IMG_002.JPG   [☐] IMG_003.JPG   [☑] IMG_004.JPG                  |
| +--------------+  +--------------+  +--------------+  +--------------+                  |
| |              |  |              |  |              |  |              |                  |
| +--------------+  +--------------+  +--------------+  +--------------+                  |
|                                                                                         |
+-----------------------------------------------------------------------------------------+
| НАЛАШТУВАННЯ ІМПОРТУ:                                                                    |
| Folder title: [ 2024-05-10_Import        ]   Delete options: (⚪ Leave files 🔘 Delete) |
| [ Import All (150) ]  [ Import Selected (3) ]  [ Cancel ]                                |
+-----------------------------------------------------------------------------------------+
```

### Основні елементи екрана імпорту:
1. **Вибір джерела (Import From Dropdown):**
   * Вибір підключеної цифрової камери, кардрідера, USB-флешки, оптичного диска або сканера.
2. **Галерея предперегляду:**
   * Відображення всіх знайдених на пристрої фотографій з можливістю точкового вибору прапорцями (`☑`).
3. **Налаштування призначення (Destination & Folder Title):**
   * Вказування вихідної папки на комп'ютері (за замовчуванням `Мої малюнки`).
   * Шаблон назви нової папки (наприклад, `YYYY-MM-DD Name`).
4. **Параметри очищення пристрою (After Importing Delete):**
   * *Leave files on card:* Залишити оригінали на карті пам'яті.
   * *Delete original files:* Автоматично видалити імпортовані файли з карти після успішного копіювання.
5. **Кнопки дій:**
   * **Import All:** Імпортувати всі знайдені файли.
   * **Import Selected:** Завантажити лише вибрані прапорцями знімки.

## 2. Вікно експорту зображень (Export Picture to Folder Dialog)

Діалогове вікно викликається через меню `File > Export Picture to Folder` або кнопку **Export** на нижній панелі дій. Воно застосовує всі неруйнівні редагування та створює готові JPEG-файли.

```
+-------------------------------------------------------------------------+
| 📦 Export to Folder                                                    |
+-------------------------------------------------------------------------+
| Export Location: [ C:\Users\User\Pictures\Exported          ] [Browse]  |
| Name of exported folder: [ Vacation_Best                          ]     |
|                                                                         |
| Image Size:                                                             |
| 🔘 Resize to: [  1024  ] pixels (pixels along long edge)               |
| ⚪ Use original size                                                     |
| [====================O====================] 800px ... 2048px           |
|                                                                         |
| Image Quality:                                                          |
| Quality: [ Automatic (Default)       ▼ ]                                |
|          (Automatic / Normal / Maximum / Minimum)                       |
|                                                                         |
| Watermark:                                                              |
| ☑ Add a watermark: [ © 2024 PhotoStudio                           ]     |
|                                                                         |
|                                                  [ OK ]     [ Cancel ]  |
+-------------------------------------------------------------------------+
```

### Параметри експорту:
* **Export Location:** Вибір теки призначення на ПК або зовнішньому накопичувачі.
* **Image Size (Розмір зображення):**
  * *Original Size:* Збереження у вихідній роздільній здатності.
  * *Resize to:* Масштабування довгої сторони фото під фіксований піксельний ліміт (наприклад, 800px, 1024px, 2048px для веб-публікацій).
* **Image Quality (Якість стиснення JPEG):**
  * **Automatic:** Оптимальний баланс між розміром файлу та якістю.
  * **Maximum / Normal / Minimum:** Ручна установка ступеня стиснення.
* **Watermark (Водяний знак):**
  * Можливість накласти довільний текстовий напис у нижній правий кут кожної експортованої фотографії.

## 3. Майстер друку (Print Layout Wizard)

Викликається кнопкою **Print** на нижній панелі або комбінацією `Ctrl + P`.

```
+-------------------------------------------------------------------------+
| 🖨️ Print Layout Wizard                                                 |
+-------------------------------------------------------------------------+
| ВИБІР МАКЕТУ ДРУКУ:           | ПРЕДПЕРЕГЛЯД СТОРІНКИ:                  |
| 🔘 Full Page (1 photo/page)   | +-------------------------------------+ |
| ⚪ 4 x 6 in (2 photos/page)    | | +-----------------+                 | |
| ⚪ 5 x 7 in (2 photos/page)    | | |                 |                 | |
| ⚪ Wallet (9 photos/page)     | | |      ФОТО       |                 | |
| ⚪ Passport (16 photos/page)  | | |                 |                 | |
|                               | | +-----------------+                 | |
| [☑] Crop to fit               | +-------------------------------------+ |
| Copies: [ 1 ▲▼ ]              |                                         |
+-------------------------------+-----------------------------------------+
| Printer Options: [ Canon PIXMA TS5000 Series  ▼ ]  [Printer Setup...]   |
|                                                 [ Print ]    [ Cancel ] |
+-------------------------------------------------------------------------+
```

### Особливості майстра друку:
* **Макети розкладки (Print Layouts):**
  * **Full Page:** Друк одного фото на увесь аркуш A4.
  * **4x6 / 5x7 / Wallet / Passport:** Автоматична компоновка 2, 4, 9 або 16 фотографій на одному аркуші паперу для економії.
* **Crop to fit (Обітка під формат):** Автоматичне підганяння пропорцій фото під формат паперу без білих полів.
* **Copies:** Кількість копій для кожного обраного знімка.

## 4. Діалог синхронізації з Google Web Albums / Google Photos

Слугує для завантаження фотоальбомів у хмару Google.

* **Account selector:** Вибір прив'язаного облікового запису Google.
* **Album Name:** Створення нового веб-альбому або вибір існуючого.
* **Access Level (Рівень доступу):**
  * **Public:** Альбом доступний усім у мережі.
  * **Unlisted (Unlisted/Limited):** Доступ лише за прямим посиланням.
  * **Private:** Приватний доступ тільки для власника акаунту.
* **Upload Size:** Вибір між безкоштовним зменшеним розміром (2048px) та оригінальною якістю.
