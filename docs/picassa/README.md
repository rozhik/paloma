# Google Picasa — Поекранна документація та графічний інтерфейс

Ласкаво просимо до детальної документації користувацького інтерфейсу та екранів класичного фотоменеджера **Google Picasa** (версія 3.9).

Google Picasa — це настільний додаток для каталогізації, перегляду, неруйнівного редагування та впорядкування цифрових фотографій і відео, який випускався компанією Google до березня 2016 року.

---

## 📌 Архітектура та принципи побудови UI

* **Неруйнівне редагування (Non-Destructive Editing):** Усі модифікації зберігаються у внутрішній базі даних та службовому файлі `.picasa.ini` в папці з зображеннями. Оригінали файлів залишаються без змін до моменту виконання явного експорту чи збереження.
* **Автоматичне сканування (Folder Scanning):** Фоновий модуль Folder Manager відстежує вибрані диски й директорії, миттєво додаючи нові медіафайли в бібліотеку.
* **Швидка навігація без вкладок:** Перехід між загальним каталогом (Library View) та редактором фото (Editor View) здійснюється подвійним кліком миші без відкриття окремих модальних вікон.
* **Буфер вибору (Photo Tray):** Нижній "піддон" дозволяє накопичувати фото з різних папок для подальшого експорту, створення колажу чи друку.
