# 04. Інструменти створення (Creation Tools)

Picasa містить вбудований комплекс творчих інструментів для створення фотоколажів, відеопрезентацій, слайд-шоу та подарункових компакт-дисків.

---

## 1. Конструктор фотоколажів (Picture Collage Creator)

Відкривається через меню `Create > Picture Collage...` або кнопку **Collage** у нижньому фотопіддоні.

```
+-----------------------------------------------------------------------------------------+
| [◀ Back to Library]   CREATE COLLAGE: [ 🎨 Settings ] [ 🖼️ Clips ]                       |
+--------------------------+--------------------------------------------------------------+
| ПАНЕЛЬ НАЛАШТУВАНЬ      | РОБОЧА ОБЛАСТЬ POLAROID / MOSAIC CANVAS                      |
|                          |                                                              |
| Collage Type:            |  +--------------------------------------------------------+  |
| [ Picture Pile        ▼ ]|  |  +------+       +---------+                            |  |
|                          |  |  |      |       |         |   +------+                 |  |
| Options:                 |  |  |      |       |         |   |      |                 |  |
| ☑ Picture Borders        |  |  +------+       +---------+   +------+                 |  |
| ⚪ Background: Solid Color|  |           +---------+                                  |  |
| 🔘 Background: Image     |  |           |         |                                  |  |
|                          |  |           +---------+                                  |  |
| Page Size:               |  +--------------------------------------------------------+  |
| [ Current Screen (16:9)▼]|                                                              |
+--------------------------+--------------------------------------------------------------+
| [ Create Collage (PNG) ]  |  [ Shuffle Clips 🎲 ]  [ Clear All ]                           |
+-----------------------------------------------------------------------------------------+
```

### 🎯 Режими макетування (Collage Types):

1. **Picture Pile (Хаотична купа фото):**
   * Вільне розташування знімків у вигляді розкиданих фотографій Polaroid.
   * Кожен знімок можна перетягувати, обертати за допомогою кругового регулятора та змінювати його масштаб.
2. **Mosaic (Мозаїка):**
   * Автоматичне підганяння кадриків різного розміру в суцільне полотно без пробілів.
3. **Frame Mosaic (Мозаїка з центральним кадром):**
   * Виділення однієї головної фотографії в центрі, оточеної дрібними мініатюрами.
4. **Grid (Сітка):**
   * Упорядковане розміщення фото у формі однакових рядків та стовпчиків.
5. **Contact Sheet (Контактний відбиток):**
   * Каталоговий лист із сіткою мініатюр та підписами файлових імен на білому або чорному тлі.
6. **Multiple Exposure (Багатократна експозиція):**
   * Художнє накладення всіх вибраних фотографій одна на одну з напівпрозорістю.

### ⚙️ Додаткові налаштування колажу:
* **Picture Borders:** Додавання білої рамки чи тіні до кожного кадру.
* **Background Color / Image:** Вибір суцільного кольору фону або використання одного із зображень як розмитого тла.
* **Page Size:** Формат підсумкового файлу (4:3, 16:9, 4x6, 5x7, Square, A4).
* **Кнопка Shuffle Clips (🎲):** Випадкове перемішування фото та кутів їх нахилу.

## 2. Створення відео та слайд-шоу (Movie Maker)

Відкривається через меню `Create > Movie...` або кнопку **Movie** на нижній панелі дій.

```
+-----------------------------------------------------------------------------------------+
| [◀ Back to Library]   MOVIE MAKER: [ 🎥 Movie ] [ 🎨 Slide ]                            |
+--------------------------+--------------------------------------------------------------+
| ПАНЕЛЬ НАЛАШТУВАНЬ ВІДЕО | ТАЙМЛАЙН ТА ЕКРАН ПРЕДПЕРЕГЛЯДУ                              |
|                          |                                                              |
| Audio Track:             |  +--------------------------------------------------------+  |
| [ Load Music... (MP3)  ] |  |                                                        |  |
|                          |  |                     ПРЕДПЕРЕГЛЯД                       |  |
| Slide Transition:        |  |                                                        |  |
| [ Dissolve             ▼ ]|  +--------------------------------------------------------+  |
|                          |  [ ▶ Play ]  00:01:24 / 00:03:45                           |
| Transition Duration:     |  --------------------------------------------------------  |
| [ 2.0 sec              ] |  ТАЙМЛАЙН СЛАЙДІВ (SLIDE STRIP):                           |
|                          |  +-----+ +-----+ +-----+ +-----+ +-----+                   |
| Slide Duration:          |  | 📷1 | | 📷2 | | 📷3 | | 📷4 | | 📷5 |                   |
| [ 4.0 sec              ] |  +-----+ +-----+ +-----+ +-----+ +-----+                   |
+--------------------------+--------------------------------------------------------------+
| Dimensions: [ 1080p Full HD ▼ ] | [ Create Movie (WMV/MP4) ] [ Upload to YouTube 🌐 ]   |
+-----------------------------------------------------------------------------------------+
```

### ⚙️ Функціональні модальні вкладки Movie Maker:

#### 1. Вкладка "Movie" (Загальні налаштування відео):
* **Audio Track:** Підключення фонового аудіофайлу (MP3, WAV).
* **Slide Transition (Тип переходу):**
  * *Cut:* Пряма зміна кадрів.
  * *Dissolve:* Плавне розчинення (Crossfade).
  * *Wipe Left / Right / Up / Down:* Зсув кадру шторкою.
  * *Push / Zoom:* Ефект наближення та насування кадру.
* **Slide Duration / Transition Duration:** Регулювання тривалості показу кожного фото (наприклад, 4 секунди) та тривалості самого переходу (1-3 секунди).
* **Dimensions (Роздільна здатність):** Вибір якості підсумкового відео (480p, 720p HD, 1080p Full HD).

#### 2. Вкладка "Slide" (Редагування конкретного кадру):
* **Text Overlay:** Додавання текстового титру поверх вибраного слайду з анімацією появи.
* **Background Color:** Колір тла для слайдів з текстом або некоректним співвідношенням сторін.
* **Full Frame Crop:** Автоматична обрізка фотографії для заповнення всього екрана без чорних смуг.

#### 3. Кнопки виводу:
* **Create Movie:** Рендеринг відео у форматі WMV / MP4 на жорсткий диск.
* **Upload to YouTube:** Пряме завантаження змонтованого відеоролика на канал YouTube.

## 3. Майстер подарункового диска (Gift CD Creator)

Відкривається через `Create > Create a Gift CD...`.

* Дозволяє записати обрані альбоми та папки на CD/DVD носій.
* **Вбудована автономна програма перегляду (Picasa Slideshow Viewer):** Автоматично додається на диск, дозволяючи отримувачу переглядати фотографії у повноекранному режимі навіть без встановленої Picasa на його комп'ютері.
* **Створення веб-галереї:** Можливість згенерувати HTML-сторінку фотогалереї безпосередньо на диску.
