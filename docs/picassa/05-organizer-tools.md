# 05. Інструменти організації та геоданих (Organizer Tools)

У цьому розділі описано спеціалізовані екрани Picasa для автоматичного розпізнавання облич, розстановки геолокаційних позначок на карті та масової обробки метаданих.

---

## 1. Екран розпізнавання облич (People Manager / Face Tagging View)

Модуль розпізнавання облич автоматично сканує бібліотеку та групує подібні обличчя в альбоми людей.

```
+-----------------------------------------------------------------------------------------+
| [≡ People Manager]   [ UNNAMED PEOPLE (128 faces)                                     ] |
+-----------------------------------------------------------------------------------------+
| ГАЛЕРЕЯ НЕРОЗПІЗНАНИХ ОБЛИЧ:                                                            |
|                                                                                         |
|  +--------------+  +--------------+  +--------------+  +--------------+                 |
|  |   [ 😀 ]     |  |   [ 😀 ]     |  |   [ 😀 ]     |  |   [ 😀 ]     |                 |
|  |  Who is this?|  |  Who is this?|  |  Who is this?|  |  Who is this?|                 |
|  |  [  Олена  ] |  |  [   Іван  ] |  | [Name person]|  | [Name person]|                 |
|  |  [✓]   [✕]   |  |  [✓]   [✕]   |  |  [✓]   [✕]   |  |  [✓]   [✕]   |                 |
|  +--------------+  +--------------+  +--------------+  +--------------+                 |
|                                                                                         |
+-----------------------------------------------------------------------------------------+
| КНОПКИ ГРУПОВОГО ПІДТВЕРДЖЕННЯ: [ Confirm All (✓) ]   [ Reject All (✕) ]                 |
+-----------------------------------------------------------------------------------------+
```

### Елементи управління People View:
1. **Секція Unnamed People (Невідомі особи):**
   * Галерея витягнутих кропів облич, які Picasa знайшла на фотографіях, але які ще не мають підписаного імені.
2. **Карточка підтвердження обличчя:**
   * **Текстове поле [Name person]:** Введення імені людини (із випадаючим списком підказок із контактів Google).
   * **Зелена галочка `[✓]` (Confirm):** Підтвердження здогадки алгоритму.
   * **Червоний хрестик `[✕]` (Reject / Remove):** Відхилення пропозиції або видалення прямокутника обличчя з фото.
3. **Персональні альбоми (Person Albums):**
   * Після надання імені створюється віртуальний альбом (наприклад, "Олена"), де відображаються всі фотографії за участю цієї людини.
   * Можливість встановити аватарку альбому (Contact Sheet Cover).

---

## 2. Екран геолокації та карти (Places View / Google Maps Integration)

Відкривається натисканням іконки геотегу `[📍 Places]` у правому нижньому кутку головного вікна бібліотеки.

```
+-----------------------------------------------------------------------------------------+
| [◀ Hide Panel]   PLACES / GOOGLE MAPS INTEGRATION                                       |
+-----------------------------------------+-----------------------------------------------+
| СІТКА ФОТОГРАФІЙ АЛЬБОМУ                | ВБУДОВАНЕ ВІКНО GOOGLE MAPS                   |
|                                         |                                               |
| [☑] IMG_001.JPG (Одеса)                 |  +-----------------------------------------+  |
| [ ] IMG_002.JPG (Не має геоданих)       |  |  [+]                                    |  |
|                                         |  |  [-]  Kyiv                              |  |
| 👉 Інструкція:                          |  |        📍 (3)                           |  |
| Перетягніть фотографію з лівої сітки    |  |                   📍 Odesa (12)         |  |
| на маркер карти для встановлення геоданих|  |                                         |  |
|                                         |  +-----------------------------------------+  |
+-----------------------------------------+-----------------------------------------------+
| [ Mark Location (📍) ]   [ Clear Geotag (🗑️) ]  | Map Type: [ Satellite ▼ ]             |
+-----------------------------------------------------------------------------------------+
```

### Особливості екрана Places View:
* **Інтегрована інтерактивна карта Google Maps:** Підтримує режими *Map*, *Satellite*, *Hybrid*.
* **Мапінг за допомогою Drag-and-Drop:** Для прив'язки координати достатньо перетягнути мишею один або декілька знімків із фотопіддону на відповідну точку на карті.
* **Маркери місць (Location Markers):** Отображають іконки-шпильки з лічильником фотографій. При кліку на маркер відкривається спливаючий карусель-переглядач усіх знімків, зроблених у даній локації.

## 3. Діалогове вікно пакетного перейменування (Batch Rename Dialog)

Викликається через меню `Tools > Batch Rename...` або гарячу клавішу `F2` при виборі декількох фотографій.

```
+-------------------------------------------------------------------------+
| 🏷️ Batch Rename (Перейменування 42 файлів)                             |
+-------------------------------------------------------------------------+
| Enter a new name for these files:                                       |
| [ Vacation_Carpathians_2024                                       ]     |
|                                                                         |
| Options:                                                                |
| ☑ Include date in filename                                              |
| ☑ Include image dimensions (e.g. 1920x1080)                             |
|                                                                         |
| Example Output:                                                         |
| Vacation_Carpathians_2024-001.jpg                                       |
| Vacation_Carpathians_2024-002.jpg                                       |
|                                                                         |
|                                                [ Rename ]    [ Cancel ] |
+-------------------------------------------------------------------------+
```

### Параметри пакетного перейменування:
* **Базовий шаблон назви:** Текстовий рядок (наприклад, `Vacation_Carpathians`).
* **Автоматична нумерація:** Додавання порядкового номера (`-001`, `-002` тощо).
* **Приєднання дати / роздільної здатності:** Можливість автоматично включити дату зйомки з EXIF у назву файлу.

---

## 4. Інші пакетні операції (Batch Tools)

В меню `Tools > Batch Edit` доступні додаткові вікна для масової обробки:
* **Batch Rotate (Груповий поворот):** Поворот усіх обраних фотографій на 90° за або проти годинникової стрілки.
* **Batch Auto Color / Auto Contrast:** Застосування автоматичних алгоритмів балансу білого до сотен фотографій в один клік.
* **Batch Captioning / Tagging:** Масове присвоєння однакових ключових слів (тегів) та підписів для групи фотографій.
